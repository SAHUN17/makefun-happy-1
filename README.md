# ai-happy-01

An entry for the make.fun bounty [ai-happy-01](https://make.fun/bounty/ai-happy-01).

The entry's image lives at `entry.png`. Running `main.py` copies it to
`/output/entry.png`, creating `/output` first if needed.

## Run

```sh
python3 main.py
```

The output is deterministic: the destination is always `/output/entry.png`.
